### ⚙️ Deskripsi Proyek  

Program ini dibuat untuk membantu mencari akar dari suatu persamaan
menggunakan metode iterasi titik tetap (Fixed Point Iteration Method).
Pengguna dapat memasukkan persamaan f(x), nilai awal (x₀),
toleransi error (ε), dan jumlah maksimum iterasi.
Program kemudian akan menampilkan hasil perhitungan setiap langkah
dan menunjukkan apakah hasilnya konvergen atau tidak.

---

💡 Tujuan:
- Memahami cara kerja metode iterasi dalam mencari akar fungsi.
- Mengimplementasikan konsep komputasi numerik dalam bentuk program Python.
- Menampilkan proses perhitungan secara otomatis dan interaktif (GUI).

---

🧩 Library yang Digunakan:
- 🪟 tkinter → untuk membuat tampilan aplikasi (GUI), jadi program bisa digunakan dengan klik tombol.
- 🎨 ttk → versi modern dari tkinter, tampilannya lebih rapi dan menarik.
- 🧮 sympy → untuk menghitung dan mengolah rumus matematika, seperti mencari nilai fungsi dan akar.
- 💬 messagebox → untuk menampilkan pesan pop-up hasil perhitungan atau peringatan error.
